# PackBottle AI

Blank HTML/CSS/JavaScript template for **PackBottle AI** (`packbottleai.com`).

Black-and-white site shell only. No page copy, images, or logo.

## Kept

- Hamburger menu (three lines) fixed at the top right; click to open the navigation dropdown
- Homepage website name: PackBottle AI
- Homepage scope
- Homepage SEO meta title, meta description, canonical URL, and page title
- Document titles on inner pages (browser tab); those pages have empty bodies

## Local preview

Open `index.html` in a browser, or:

```bash
npx --yes serve .
```
